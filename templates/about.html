Academic Research Paper

Predicting Student Academic Performance Using Decision Tree and Random Forest Machine Learning Models

Authors Norjeane P. Centino & Rouge P. L. Saludes
Institution University of Mindanao, Matina, Davao City, Philippines
Dataset Size 6,607 Student Records (20 Variables)

1. Introduction & Problem Description

Student academic performance is an important concern in educational institutions because it reflects how well students are progressing in their studies. Teachers and academic staff regularly monitor grades, attendance, participation, and other indicators to determine whether students are meeting expected learning outcomes. However, evaluating these multivariate factors for a large number of students simultaneously can become challenging.

Academic performance is not determined by a single factor. Previous examination scores, class attendance, study habits, access to learning resources, tutoring sessions, parental involvement, and lifestyle conditions all interact. In this study, student academic performance is framed as a three-level classification problem: Low (55–64), Medium (65–69), and High (70–101).

Core System Principle: The purpose of the proposed machine learning system is not to replace teachers or make automated academic verdicts. Instead, the prediction results provide objective decision support so educators can identify at-risk students early and deliver timely interventions.
Research Objectives

Project Goals

  • General Objective: Develop an ML system to predict student performance by analyzing educational factors using Decision Tree and Random Forest models and compare their predictive capabilities.
  • Preprocess the Kaggle student dataset by resolving missing values with mode imputation and one-hot encoding.
  • Train baseline Decision Tree (Gini criterion) and Random Forest (200 trees) classifiers with stratified 80/20 train-test splits.
  • Evaluate models using accuracy, weighted precision, recall, F1-scores, and confusion matrices.
  • Deploy an interactive system to support early academic intervention.
